## 第一周：注意力机制与轻量化（从 CNN 到 Modern CNN）

**目标：** 掌握“魔改”CNN 最常用的手段（即插即用的注意力模块），学会自主设计模块（Goal 1）。

- **理论核心：**
    - **注意力机制 (Attention Mechanisms):** 重点学习 **SE-Block (Squeeze-and-Excitation)** 和 **CBAM (Convolutional Block Attention Module)**。
        - *为什么学它：* 这是最简单的“魔改”手段。在 ResNet 的 Residual Block 里插一个 SE 模块，立马就能发一篇水准不错的论文（在几年前），现在则是基础操作。
    - **轻量化卷积:** 学习 **MobileNet V1/V2/V3** 中的 **Depthwise Separable Convolution (深度可分离卷积)** 和 **Inverted Residuals (倒残差结构)**。
        - *为什么学它：* 现代网络为了快，几乎都在用这种结构，而不是 ResNet 标准的 3x3 卷积。
- **代码实战 (Goal 1):**
    - **任务：** 自己手写一个 `SEBlock` 类，并将其嵌入到你现有的 ResNet 代码中。
    - **技能点：** 掌握 `GlobalAveragePooling`，理解 `Channel` 维度的压缩与激励，学会使用 `nn.ModuleList` 和 `forward` 函数中的张量形状变换。

## 第二周：视觉 Transformer 的革命（前沿知识）

**目标：** 跨过 CNN 的舒适区，进入 Transformer 时代（Goal 2）。目前的前沿论文有 80% 都与 Transformer 相关。

- **理论核心：**

    - ViT (Vision Transformer): 必须读原文。理解 Patch Embedding（怎么把图片切块变成向量）和 Self-Attention（自注意力）公式。

        

        $$\text{Attention}(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$$

    - **Swin Transformer:** 目前的工业界标杆。重点理解 **Shifted Window (移动窗口)** 机制，它是如何解决 ViT 计算量过大问题的。

- **代码实战 (Goal 2):**

    - **任务：** 阅读 `timm` (PyTorch Image Models) 库中的 ViT 源码。不要从头写，要学会**读**。
    - **技能点：** 熟练使用 `einops` 库（处理 Transformer 维度的神库，如 `rearrange(x, 'b c (h p1) (w p2) -> b (h w) (p1 p2 c)', p1=patch, p2=patch)`）。

## 第三周：现代训练技巧与 ConvNeXt（复现能力的基石）

**目标：** 学习“隐性知识”。很多论文复现不出来，不是模型结构错了，而是训练技巧（Trick）没用对。

- **理论核心：**
    - **ConvNeXt:** 这是一篇必读论文。它用 2020 年代的训练技巧“现代化”了 ResNet，告诉我们 CNN 不比 Transformer 差。
    - **训练 Tricks (Bag of Specials):**
        - **数据增强:** Mixup, CutMix, RandAugment.
        - **正则化:** Label Smoothing, Stochastic Depth (DropPath).
        - **优化器:** AdamW vs SGD, Cosine Annealing LR (余弦退火学习率).
- **代码实战 (Goal 3):**
    - **任务：** 尝试复现 ConvNeXt 的核心 Block。
    - **技能点：** 学习如何写一个健壮的 `Trainer` 类，或者熟悉 `HuggingFace` / `Lightning` 的训练流。学会配置 `Optimizer` 的参数组（比如 weight decay 不应用于 Bias）。

## 第四周：综合复现与模块设计实战

**目标：** 综合运用，像做科研一样去写代码。

- **任务：** 选择一个具体的小任务（比如 CIFAR-100 分类或你之前的蔬菜分类），设计一个 **Hybrid Network (混合网络)**。
    1. **Backbone:** 使用 ResNet 的前几层提取特征。
    2. **Neck:** 接一个你第一周设计的 Attention 模块。
    3. **Head:** 尝试用 Transformer Block 处理高层特征（可选）。
    4. **训练:** 使用第三周学的 Mixup 和 Cosine Annealing。
- **技能点：** 调试网络梯度（检查哪里梯度消失了），使用 TensorBoard/WandB 监控训练曲线。

## 必读论文清单 (按优先级排序)

为了“了解前沿知识”，这几篇是目前的基石：

1. **ResNet:** *Deep Residual Learning for Image Recognition* (你已学完)
2. **ViT:** *An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale* (Transformer 进军视觉的开山之作)
3. **Swin Transformer:** *Hierarchical Vision Transformer using Shifted Windows* (ICCV 2021 最佳论文，目前的通用骨干)
4. **ConvNeXt:** *A ConvNet for the 2020s* (连接 CNN 和 Transformer 的桥梁，极佳的复现练习材料)
5. **MAE:** *Masked Autoencoders Are Scalable Vision Learners* (何恺明大神的自监督学习，代表了目前的趋势)

## 给你的“复现牛人论文”的建议 (Tips)

1. **不要只看论文，要看官方 Repo:** 论文里的公式是给人看的，代码里的细节（初始化方法、Padding 怎么加、LayerNorm 放在前面还是后面）才是给机器跑的。
2. **善用 `debug` 工具:** 复现论文时，最重要的是**对齐 Tensor 的 Shape**。在 `forward` 函数里多写 `print(x.shape)` 或者使用 PyTorch 的 Hook 机制查看中间层输出。
3. **魔改基于 `timm`:** 这是一个宝藏库，里面实现了几乎所有 SOTA 模型。你想设计模块时，参考它的代码结构（如何写 Config，如何解耦 Model 和 Layer）是进步最快的方式
