## 2 配置本地的python环境

> 如果电脑里面有了一个python的环境，而且这个环境正在使用，但是我们不想破坏这个环境的时候就需要安装一个[虚拟环境](#2-1 需要配置虚拟环境)。
> 如果电脑里面啥都没有，并且以后大概率不会使用python那就直接装就完了，不需要配置[虚拟环境](#2-2 不需要配置虚拟环境)。

### 2-1 需要配置虚拟环境

首先需要安装[ Anaconda清华源](https://mirrors.tuna.tsinghua.edu.cn/anaconda/archive/) 点击链接，进入网页。

![image-20250904092953737](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904092954719-1029233820.png)

找到一个适合你电脑的文件进行下载，我的电脑是$64$位的$Windows$因此选择这个。

![image-20250904093111922](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904093112807-678577635.png)

点击便可以直接进行下载。下载完毕之后进行安装。

安装过程中需要注意不要安装在**C盘**，安装完毕之后将Anaconda的三个地址添加在你的环境变量中。

1. `E:\AppInstallion\0_4_annaconda`，你的安装文件夹。
2. `E:\AppInstallion\0_4_annaconda\Scripts`，你的安装文件夹下面的这个文件夹。
3. `E:\AppInstallion\0_4_annaconda\Library\bin`，你的安装文件夹下面的这个文件夹。

有了这三个地址之后，在搜索框里面搜索**环境变量**。

![image-20250904093758368](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904093759416-1533034409.png)

然后打开。

![image-20250904094057907](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904094058570-1623512229.png)

点击新建，把文件位置复制进去就可以了。

**注意：一定要连按三个确定，不是直接叉掉对话框退出！！！**

完成之后就在电脑搜索框里面搜索$Anaconda$，进入这个$prompt$之中。

![image-20250904094402797](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904094403480-1065765349.png)

首先新建一个新的环境。

```cmd
conda create -n class python=3.11
```

![image-20250904094642650](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904094643325-1216716013.png)

回车安装环境

![image-20250904094732883](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904094733443-1846178373.png)

这个地方输入`y`，然后回车。

![image-20250904094907170](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904094907835-1003111620.png)

出现了上面这个图片就安装完毕。

查看自己是否正确安装。

```cmd
conda env list
```

![image-20250904095006467](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904095007029-1986246397.png)

看到了这个名字说明安装正确。
安装完成后，激活该虚拟环境。

```cmd
conda activate class
```

![image-20250904095107775](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904095108272-1642943139.png)

前面变成了`class`说明激活成功。

然后安装`README`文件中要求安装的库。由于这个国内网络原因，这里采用清华源进行安装。

首先进入自己[下载项目文件](#1 下载项目)的地址。

![image-20250904095341562](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904095342342-769509697.png)

将地址进行修改

```cmd
E:\33836\Documents\appdata\qq\WeBan-main\WeBan-main #原本的地址
cd /d E:\33836\Documents\appdata\qq\WeBan-main\WeBan-main #修改后的代码
```

把下面这个复制到`prompt`之中。

![image-20250904095534636](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904095535285-1718899868.png)

然后开始安装库函数

```cmd
pip install ddddocr -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install loguru -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install pycryptodome -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

这四条分别复制进去之后，便完成了环境的搭建和配置。

## 4 程序运行

如果是虚拟环境那就进入`prompt`，如果是无虚拟环境那就`Win+r cmd`。
进入这个命令行窗口。首先和上面样先进入你的文件夹。

将地址进行修改

```cmd
E:\33836\Documents\appdata\qq\WeBan-main\WeBan-main #原本的地址
cd /d E:\33836\Documents\appdata\qq\WeBan-main\WeBan-main #修改后的代码
```

把下面这个复制到**命令行窗口**之中。

> **注意：对于虚拟环境的同学首先需要将自己的虚拟环境激活！！！**  `conda activate class`

![image-20250904102007615](https://img2024.cnblogs.com/blog/3693258/202509/3693258-20250904102008202-226596836.png)

然后输入指令

```cmd
python main.py
```

即可自行运行。
